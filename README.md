## 🌐 Como Executar Localmente

Você pode abrir o arquivo `index.html` diretamente em qualquer navegador ou rodar um servidor local simples:

```bash
# Com Node.js
npx serve .

# Ou com Python
python -m http.server 8080
```

## ☁️ Deploy no Cloudflare Pages

1. Acesse o painel da [Cloudflare](https://dash.cloudflare.com/) > **Workers & Pages**.
2. Conecte este repositório do GitHub ou faça upload direto dos arquivos.
3. Nas configurações de build:
   - **Build command:** *(deixe em branco)*
   - **Build output directory:** `/`
4. Clique em **Save and Deploy**. Seu site estará no ar com HTTPS gratuito e CDN global!
